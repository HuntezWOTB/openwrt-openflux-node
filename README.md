# OpenFlux-нода на домашнем роутере OpenWrt

Используем OpenFlux как связь с домашним роутером OpenWrt: роутер работает
выходной нодой в интернет, а телефон/ноутбук подключается к нему из любой сети
через общий документ. Публичный IP на роутере не нужен — нода сама подключается
наружу к документу, входящих портов не открывает.

Проверено на Xiaomi Mi Router AX3000T (aarch64, OpenWrt 25.12.x), режим `l4`.

## Как это устроено

```
телефон/ноутбук (клиент) ⇄ общий документ ⇄ домашний роутер (нода) ⇄ интернет
```

Обе стороны подключаются к одному общему документу как клиенты облака.
Документ работает общей точкой встречи: что одна сторона туда записала,
облако само отдает второй. Поэтому NAT и отсутствие публичного IP не мешают.

## Установка одной командой

На роутере, из корня репозитория:

```sh
sh install.sh
```

Скрипт сам: скачает бинарь OpenFlux под архитектуру роутера, создаст общий
секрет `/etc/openflux/secret.txt`, поставит панель `Службы -> OpenFlux`
и включит автозапуск. Дальше — по `docs/01-quickstart.md`.

Вручную по шагам — `install_openflux.sh`, затем
`luci-app-openflux/install_luci.sh`.

## Состав

```
install.sh                  # одна команда: бинарь + секрет + панель + автозапуск
install_openflux.sh         # бинарь OpenFlux + общий секрет
check.sh                    # диагностика: процесс, конфиг, логи
client.conf.example         # пример второй стороны (телефон/ноутбук)
luci-app-openflux/          # пакет LuCI: Службы -> OpenFlux
  menu.d/                   # пункт меню
  rpcd/                     # права доступа
  htdocs/.../view/openflux.js  # страница настроек + блок проверки доступа
  root/etc/config/openflux  # UCI-конфиг по умолчанию
  root/etc/init.d/openflux  # procd-сервис (читает UCI)
docs/                       # пошаговые инструкции
```

## Безопасность

- Общий секрет (`/etc/openflux/secret.txt`, права `0600`) одинаковый с обеих
  сторон. Не публикуйте его и ссылку на документ.
- Куки и логи держим в `/tmp` (RAM), чтобы не изнашивать флеш роутера.
- Репозиторий не содержит секретов: см. `.gitignore`.

## Совместимость

- OpenWrt 25.x с современным LuCI (ucode/JS). Старый Lua-LuCI не поддерживается.
- Готовые билды: `amd64`, `arm64`, `arm`. Для `mips/mipsle` соберите бинарь
  на ПК вручную — команда в `docs/01-быстрый-старт.md`.
- Режим ноды — `l4` (пользовательский прокси, без root-функций и RAW-сокетов).
